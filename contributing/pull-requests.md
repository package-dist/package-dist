# Pull Requests

## Submitting changes

To submit changes to the project, you must:

1. Fork this project on GitHub following the [official instructions](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo)
2. Create a dedicated branch with your changes. Do not commit your changes to `main`.
3. Commit your changes to your branch, following the [commit messages](./commit-messages.md) guidelines.
4. Push your changes to the branch in your fork.
5. Create a GitHub pull request from your fork, following the [official instructions](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork)
