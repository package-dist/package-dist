# Contribution Guide

## Submitting Code Changes

Contributions should be done in a fork of this repository and submitted with a GitHub pull request.
Review the [pull request process](./contributing/pull-requests.md) to learn more.

Commit messages in pull requests must adhere to the project
[commit message standards](./contributing/commit-messages.md), which include:

- Conventional commit formatting, with separate subject line and body text.
- Content that explains _what_ changed and _why_, instead of _how_.
- Developer Certificate of Origin ([DCO](https://developercertificate.org/)) sign-offs.
